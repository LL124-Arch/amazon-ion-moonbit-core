# 初审对照与提交前整改

核对日期：2026-09-16

## 当前结论

项目已经具备初审所需的主要证据：公开源码、清晰范围、Apache-2.0 许可证、示例、fixture、测试、文档、兼容性记录和可追踪变更记录。CI 格式化、模块元数据和官方 Ion 差分实验已在本地完成对应整改；Mooncakes 发布仍按用户要求保持关闭，不应表述为已发布。

## 已完成整改

1. **CI 格式化：** 根据最新公开 CI 工具链产生的尾逗号差异调整源码，工作流改为 `moon fmt --check`，并保留多目标测试与构建任务。
2. **模块元数据：** `moon.mod` 已填入仓库地址 `https://github.com/LL124-Arch/amazon-ion-moonbit-core`；模块名、GitHub 归属和计划中的包名统一为 `LL124-Arch/amazon-ion-moonbit-core`。
3. **官方差分测试：** `roundtrip_lab` 使用 `amazon-ion/ion-js` 5.2.1，覆盖标量、注解 struct、重复字段、decimal、timestamp、blob/clob、二进制 round-trip 和截断输入拒绝。
4. **公开开发记录：** 已补充 `CHANGELOG.md`、兼容性矩阵、互操作说明、工具链说明和本地发布准备记录。
5. **重合审计：** 已按日期查询 Ion 全称、扩展名、MIME、实现名、parser/decoder/encoder/serializer 和仓库名等关键词，并记录查询结果与判定边界。

## 仍需人工确认的事项

- 不能执行 `moon publish`：当前本地 `moon whoami` 显示的缓存账号不是 `LL124-Arch`，且用户已明确要求不发布到 Mooncakes.io。因此本仓库只保留发布准备和本地验证证据。
- GitHub Actions 的绿色结果需要在用户确认后推送当前改动再观察；本地旧版 MoonBit formatter 与 CI 最新 formatter 的尾逗号规则不同，不能用旧版 `moon fmt` 覆盖当前 CI 风格。
- 如组委会要求持续公开开发轨迹，可在 GitHub 账号确认后补充真实的 issue 或兼容性讨论；当前已通过仓库内变更记录和互操作文档提供可审查的开发轨迹。

## 材料表述边界

- 使用“覆盖声明范围内的 Ion 1.0 子集”，不写“完全兼容 Ion”。
- 使用“已完成 Mooncakes 发布准备但未发布”，不写“Mooncakes 已上线”。
- 将本地多后端测试与公开 CI 结果分开描述。
- Ion 1.1、Ion Schema、Ion Hash、shared symbol catalog 和完整流式 API 均属于后续扩展，不写成首版能力。
